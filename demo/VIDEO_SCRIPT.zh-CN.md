# Repurpose Mind — 视频分镜脚本与中文旁白

> **用途：** 为 Creative Minds Jam 提交录制一段 1.5–2 分钟的产品走查视频。  
> **界面语言：** 英文（按之前决定，demo 视频使用 English UI；本脚本的「屏幕操作」列引用的就是英文界面上的真实文字）。  
> **分辨率：** 1280×800，浏览器 Chrome，窗口最大化，显示系统光标。  
> **总时长目标：** 约 1:50（可剪到 1:40）。  
> **关键演示点：** 本版用「中文原稿 + 英文界面」走查，顺带证明「输出语言跟随界面语言，而非原文语言」。

---

## 1. 故事线（四个节拍）

1. **痛点** —— 一个想法，五个平台，五种写法。
2. **方案** —— Repurpose Mind：一次写作，处处适配，背后是一颗「持久 Mind」。
3. **实证** —— 现场创建 → 改编 5 平台 → 展示质量 → Mind 学习 → 刷新证明持久。
4. **彩蛋** —— 多语言隔离（EN / 简中 / 繁中 记忆互不相通）。

---

## 2. 录制前准备清单

- [ ] 后端运行在 `:3001`（真实 LLM 模式），前端在 `:5173`。
- [ ] Chrome 打开 `http://localhost:5173/`，**窗口最大化**。
- [ ] 右上角语言切换 → 点 **EN**，确认界面是英文。
- [ ] *（可选，做"从零学习"的干净演示）* 清空英文 Mind 记忆：
  ```bash
  # 安全：只删英文 learned_pref 记忆，不删库
  sqlite3 "Repurpose Mind/repurpose-mind.db" "DELETE FROM mind_memory WHERE lang='en' AND key LIKE 'learned_pref_%';"
  ```
  然后刷新页面，**Remembered Preferences** 面板会变空。
- [ ] 关闭无关标签页 / 通知；隐藏 macOS 菜单栏（⌥⌥ 或演示模式）让画面干净。
- [ ] 准备一段中文原稿文本，录制时直接粘贴（见下方）。

**示例中文原稿（可直接粘贴）：**

> 我们的新款 AI 会议笔记工具，能在几秒内把每场会议整理成清晰的任务清单。它会加入你的通话、记录关键决策，并起草团队可以立刻执行的跟进事项。远程团队每位成员每周能省下约 5 小时——这些时间以前都浪费在手动重写笔记上。

## 4. 独立中文旁白（可直接配音 / TTS）

```
[0:00] 如果你做内容，肯定懂这种痛苦：一个好点子，要发到五个平台，就得写成五种完全不同的风格。
       X 要钩子，小红书要温度，邮件通讯要深度。全靠手写改写，最黄金的时间就这么耗掉了。

[0:12] Repurpose Mind 是一个跨平台内容改编助手，核心是一颗会"持久记忆"的 Mind——
       它学习你的语气，把一篇草稿改写成每个平台专属的格式，还能用你选的语言输出。

[0:22] 我们先从一篇原稿开始。标题我手写，原文我贴一段中文——这是唯一需要我动手写的东西。

[0:45] 然后我选平台：X、TikTok、YouTube、小红书、Newsletter。点一下 Create & Adapt，
       Repurpose Mind 就调用大模型，为每个平台生成量身定制的版本。
       注意我贴的是中文原稿，但界面是英文——所以生成的版本全是英文。

[1:08] 看生成结果。X 拿到一句 280 字以内的强钩子；Newsletter 变成结构清晰的邮件，还带明确的行动号召。
       每个版本都保留我的核心信息，绝不会编造事实。

[1:22] 真正让它"属于你"的，是这里。每次改编之后，Mind 都会默默学习你的偏好——
       品牌语气、各平台调性，甚至像"X 上用提问式开头"这样的小习惯。
       它写进本地数据库，所以重启也不丢。

[1:36] 看这个——我刷新一下页面。记忆还在。关掉程序、重启服务、下周再回来，你的 Mind 都记得。

[1:46] 而且它说你的受众的语言。切到中文，界面、品牌语气、记忆全都跟着变——
       英文和中文的 Mind 完全隔离。一个工作台，多种声音，互不串味。

[2:00] Repurpose Mind——一次写作，处处适配，并且越用越懂你。为 Creative Minds Jam 而做。
```

## 5. 录制提示

- **光标：** 用系统默认箭头，移动果断（不抖）。每个 chip 点前停约 0.5 秒。
- **输入：** 第 3 镜手敲标题更"真实"，约 40 字/分；长原文直接粘贴即可。
- **节奏：** 让第 4 镜的转圈跑满约 4 秒——它直观证明是真在调大模型。
- **构图：** 第 5–7 镜把 **② Mind Memory** 和 **⑤ Content Versions** 留在画面里，那是 payoff。
- **音频：** 旁白单独录（安静环境）叠在屏幕画面上，消掉点击声；或直接用上面第 4 节的 TTS 文本。
- **结尾：** 把仓库链接占位换成你实际的提交地址。

## 6. 本脚本证明的卖点（对应项目设计）

| 镜   | 证明的卖点                                    |
| --- | ---------------------------------------- |
| 4–5 | 多平台适配，长度 / 格式 / 语气贴合各平台                  |
| 4   | *额外：* 中文原稿 + 英文界面 → 输出英文（输出语言跟随界面，不跟随原文） |
| 6   | 持久 Mind *学习* 偏好（品牌语气 + 平台调性）             |
| 7   | 记忆跨刷新 / 重启保留（SQLite 落盘）                  |
| 8   | 多语言隔离——EN / 简中 / 繁中 的 Mind 互不共享          |
| 3   | 最小输入——一次写作，处处适配                          |

> 注：若你更想要「纯中文界面」的录屏版本，只需把录制前清单里的 EN 改成**简中**，并把第 3 镜的原稿也换成中文，其余分镜不变即可。
